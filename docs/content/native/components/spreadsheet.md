## How it works

Spreadsheet uses the same formula evaluator as the React component. Data is an array of rows containing strings, numbers, booleans, or null. Formula strings start with `=` and support references, ranges, arithmetic, SUM, AVERAGE, MIN, MAX, COUNT, and custom functions. Errors render as cell values, including cycles and invalid references.

The consumer owns data. Apply each onCellsChange batch to a new data array; batches contain row, column, value, and previous. Root keeps selection, edit drafts, column widths, and a bounded history of those batches. Read-only mode blocks edits, paste, clear, fill, undo, and redo while allowing selection and copy. Omitting onCellsChange also makes the sheet read only.

Compose FormulaBar, NameBox, FormulaInput, Container, Header, HeaderRow, Body, and Empty. Container supplies the table parts when its children are omitted. Give Root a bounded height. Body renders only visible rows plus overscan; offscreen editing rows stay mounted. Columns are also windowed. frozenRows and frozenColumns keep the leading cells visible, alongside the column letters and row numbers. ColumnHeader includes ResizeHandle; RowHeader includes RowResizeHandle. Drag their edges to resize columns or rows live, or use accessibility increment/decrement/reset actions. rowHeights, defaultRowHeights, and onRowHeightsChange control individual row heights; minRowHeight defaults to 24px. rowHeight remains the default and the column-letter header height.

Tap a cell to select it, double tap it or use Toolbar’s Edit button to edit. FormulaInput edits the raw formula or value. Return commits and moves down. Apply commits without moving; Cancel discards the draft. Selecting another cell commits an active draft. Long press a destination to extend the selection, or enable Select range and tap its endpoint. Row and column headers select their entire ranges.

Toolbar supplies touch actions for Copy, Cut, Paste, Clear, Select range, Fill, Apply, and Cancel. Clipboard access uses expo-clipboard and reports failures without changing cells. Clipboard text is tab/newline delimited. A single pasted value fills the selected range; a block pastes from its top-left corner and is clipped to the sheet bounds. Copy uses displayed values, matching desktop. For filling, tap the small FillHandle or Toolbar’s Fill button, then tap the destination cell. Numeric sequences continue their step and formulas shift relative references. Tap Fill again to cancel.

UndoTrigger and RedoTrigger replay the consumer’s edit batches. Context exposes useSpreadsheet() state and operations for custom controls, including focusCell, select, startEditing, commitEditing, cancelEditing, copyRange, pasteText, and scrollToCell. Selection and column widths can be controlled independently.

The browser renderer also supports arrow navigation, Shift+arrow range extension, Home/End, PageUp/PageDown, Enter/F2 editing, Delete, select-all, and undo/redo keys. Native hardware-keyboard navigation, drag-to-select/fill with edge autoscrolling, and complete screen-reader grid navigation are not yet implemented. Touch fill uses a destination tap rather than the desktop drag gesture. The header sits outside the vertical scroll view. Frozen columns and row numbers live outside the horizontal scroller and share one vertical scroll view with the moving cells, so their horizontal position never depends on scroll events or compensating transforms. Only the moving column headers follow the horizontal offset through a UI-thread transform. React receives coarse scroll updates only for virtualization. Physical-device high-speed scrolling still requires verification. Use Toolbar for native clipboard actions. Headers and cells follow the same typography, borders, selection colors, and light/dark tokens as desktop; inputs reuse arkcn Input.

Resize gestures use react-native-gesture-handler. Root provides its gesture root; install the Expo-compatible package with `npx expo install react-native-gesture-handler`. The native pan owns touches over the handle, preventing ancestor scroll views from scrolling during a resize. Cell dimensions, neighboring positions, and frozen panes update together on the UI thread while dragging. React sizing state and controlled callbacks commit once on release; cancelled gestures restore the original dimensions.
