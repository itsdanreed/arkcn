## Aspect Ratio

Root fills its parent's width and reserves height using `ratio` (width divided by height). The default is a square.
Ratios must be finite and greater than zero. Put the desired width on a parent View; its width can change without
measuring or updating the ratio in JavaScript.

Children and native View props, including `ref`, apply to the inner content box. Styles merge after absolute-fill
positioning, matching the web part. Put image, video, or other content inside Root and style it explicitly.
