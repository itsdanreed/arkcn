# arkcn React Native

Fifty-five native components for Expo and React Native: Button, Card, Input, Textarea, Badge, Separator, Spinner, Skeleton, Checkbox, Switch, RadioGroup, Tabs, Collapsible, Progress, Alert, Avatar, Toggle, ToggleGroup, Accordion, InputGroup, ButtonGroup, Label, AspectRatio, Field, Fieldset, NumberInput, RatingGroup, Editable, Pagination, SegmentGroup, Breadcrumb, Empty, Kbd, Pin Input, Item, Steps, Highlight, Format, Tags Input, App Shell, Dialog, Alert Dialog, Sheet, Clipboard, Activity Feed, Timer, Message, Bubble, Marker, Attachment, Table, Password Input, Scroll Area, Slider, and Spreadsheet.

```tsx
import { Button, Card, Input } from "@multicomma/arkcn-react-native"
```

Uses React 19 and React Native 0.81 or later. Components follow system appearance; customize colors with
`NativeThemeProvider`. Use `onPress`, `onChangeText`, native accessibility props, and `style` overrides.
No Ark UI, React DOM, or Tailwind runtime is required. Dialog and Alert Dialog use `expo-blur` for their native backdrop; install it with `npx expo install expo-blur`. Clipboard uses `expo-clipboard`; install it with `npx expo install expo-clipboard`. Attachment uses Expo SDK 57’s `@expo/ui` masked view for upload shimmer and scroll fades; install it with `npx expo install @expo/ui`. Non-Expo apps must configure Expo modules to use these components. Other components can be imported individually without Expo.

See the repository [native guide](https://github.com/itsdanreed/arkcn/blob/main/docs/content/react-native.md).
This is an initial component set, not full parity with the web catalog.

Motion uses Reanimated 4 with Worklets; SVG icons use react-native-svg and lucide-react-native. Install versions compatible with your Expo SDK or React Native release, configure Worklets, and load Geist for matching typography. The native guide covers setup and reduced-motion overrides.

## Porting status

Slider is included in the registry, docs, and Expo catalog. Browser comparisons match desktop track/thumb dimensions, typography, and spacing in light/dark themes; keyboard Home/End/PageUp and pointer dragging reach the expected values. iPad checks cover track taps, independent range values, commit callbacks, decimal accessibility adjustments, RTL and vertical endpoints, disabled/read-only guards, dark mode, and reduced motion. Automated tests cover snapping, thumb separation, controlled values, and quick-tap measurement timing. Simulator drag automation produced no movement; physical touch dragging, Android visuals, and full VoiceOver traversal remain unverified. Markers currently support horizontal layouts.

Scroll Area is included in the registry, docs, and Expo catalog. Browser comparisons match the desktop dimensions, typography, dividers, and scrollbar in both themes; browser thumb dragging reaches the end. iPad checks cover light/dark themes, reduced motion, track clicks, accessibility increment/decrement, programmatic scrolling, nested button actions, disabled guards, and shrinking/restoring content. Automated tests cover proportional geometry, clamping, drag calculations, callback forwarding, and overflow removal. Two-axis areas now support independent offsets, explicit horizontal/vertical tracks, and a shared Corner. iPad checks verify scrolling to both ends, preserving the vertical position while horizontal content shrinks, and removing/restoring tracks as each dimension fits; the two-axis example is also checked in dark mode with reduced motion. Simulator automation did not move either the native content or thumb with drag gestures, so touch dragging, momentum, RTL scrolling, Android visuals, and full VoiceOver traversal remain unverified.

Password Input is included in the registry, docs, and Expo catalog. Browser checks match desktop text size, input height, and light/dark styling. iPad checks cover label focus, typing across secure/visible toggles without text loss, controlled reset, invalid/disabled/read-only states, and reduced motion. Automated tests cover independent value/visibility state, controlled visibility, blocked edits/toggles, and RootProvider composition. Android secure-entry behavior, real password-manager autofill, and VoiceOver navigation remain unverified.

Table is included in the registry, docs, and Expo catalog. Browser comparisons match the desktop typography, row dividers, and column sizing within pixel rounding. iPad checks cover light/dark themes, selection, reduced motion, totals, spanning empty cells, and automatic column resizing when rows are added or removed. Automated tests cover shared section widths, selected state, fragment rows, and last-row dividers after removal. Narrow horizontal scrolling was exercised, but its full gesture range, Android visuals, RTL scrolling, and VoiceOver navigation remain unverified.

Attachment is included in the registry, docs, and Expo catalog. iPad checks cover all sizes and states, narrow filename truncation, light/dark themes, upload shimmer, reduced motion, scrolling edge fades, independent card/action callbacks, disabled cards, and vertical image previews. Automated tests cover shimmer lifecycle, disabled guards, action independence, group height measurement, and removal of obsolete snap points. Android visuals, RTL scrolling, and VoiceOver navigation remain unverified.

Marker is included in the registry, docs, and Expo catalog. Browser comparisons match the desktop example’s typography, icon size, spacing, and border in light/dark themes. Native contract tests cover passive rendering, link semantics, and disabled navigation. iPad checks cover narrow wrapping, RTL, both themes, reduced motion, and link activation. Android visuals and screen-reader navigation remain unverified.

Message and Bubble are included in the registry, docs, and Expo catalog. Browser examples match web typography, dimensions, alignment, and colors in both themes. iPad checks cover wrapping at 260px, RTL, dark/light themes, reduced motion, variant surfaces, message activation, and direct taps on overlapping reaction buttons. Automated tests cover dynamic footer detection, inherited alignment, independent actions, and measured reaction placement. The iOS 26.3 simulator displays emoji as missing glyphs even in plain native Text; physical-device emoji rendering, Android visuals, and screen-reader navigation remain unverified.

Timer is included in the registry, docs, and Expo catalog. Browser comparisons match the desktop number blocks, typography, and controls in both themes. Automated tests cover countdown/count-up completion, pause/resume, reset/restart, interval changes, foreground catch-up, and cleanup. The iPad Release app builds and renders the timer; isolated device background-return verification, Android visuals, and screen-reader checks remain outstanding.

Activity Feed is included in the registry, docs, and Expo catalog. Browser comparisons match the audited web layout in both themes. iPad checks cover dynamic loading, narrow wrapped details, right-to-left connectors, empty/reset states, relative times, and nested actions in both themes. Native tests verify connector boundaries, conditional/fragment children, loading state, and action callbacks. Android visuals and assistive-technology navigation remain unverified.

Clipboard is included in the registry, docs, and Expo catalog. iPad checks cover real copy/paste, source changes, success feedback, disabled controls, and light/dark themes. Automated tests cover failed and pending writes, repeat copies, timeout reset, controlled updates, and unmount cleanup. Android interaction and visual verification remain outstanding.

App Shell is available in the registry and docs, with a full-screen Expo demo. iOS 26.3 checks cover portrait drawers, landscape sidebar/floating/inset variants, icon/offcanvas/none collapse modes, subnavigation, search, notification counts, light/dark themes, and reduced motion. Utility menus use native modal dialogs; routing and search data remain consumer-owned. Android visual verification, hardware shortcuts, and desktop hover behavior are not covered.

Tags Input is included in the registry, docs, and Expo catalog. The browser example matches web styling in both themes. Native tests cover independent controlled tags/drafts, duplicate and limit rejection, validation, bulk insertion, editing, and disabled/read-only guards. iOS checks cover fast consecutive Return submissions with draft clearing, adding with Done and delimiters, two-step Backspace removal, long-press editing, controlled resets, validation rings, dark mode, and reduced motion. Android interaction and visual verification remain outstanding.

Highlight and Format are implemented and available in the Expo catalog. Highlight's literal matching, whole-word matching, multiple queries, live edits, and light/dark colors are checked. Browser rendering matches the web example. Native rounded backgrounds are measured behind the text; iOS checks cover wrapped phrases, explicit newlines, repeated matches, centered text, changing widths, live queries, and theme switches. Format is verified on iOS/Hermes for numbers, currency, bytes, relative time, locale overrides, and 12/24-hour time in both themes. It includes feature-detected relative-time/plural-rules polyfills with English data; other relative-time locales require importing their data. English short byte units normalize spacing to match the web. Other locale details remain dependent on host Intl. Android visuals, mixed-direction highlight text, and automatic font shrinking remain unverified.

Steps is included in the registry and Expo catalog. Web/native browser comparisons pass in both themes. iOS 26.3 Simulator checks cover horizontal/vertical layouts, linear navigation, blocked invalid steps, preserved input, completion, reset, light/dark styling, and reduced motion. Automated checks cover controlled state, panel mounting, validation bypass, and navigation boundaries. Android visual verification remains outstanding.

Pin Input and Item are included in the registry and Expo catalog. Browser parity, automated checks, and iOS 26.3 Simulator checks pass. Pin Input was verified for continuous typing, completion callbacks, backspace from filled and empty cells, replacement, formatted-code paste into a later cell, controlled updates, disabled entry, invalid-character rejection, and light/dark styling with reduced motion. Item's example layout and action were verified in both themes. Android visual verification and real SMS autofill remain outstanding.

Field and Fieldset now cover labeled inputs, multiline values, descriptions, required indicators, validation, and disabled groups. Native inputs use 14px text at every viewport width. Number Input adds bounded decimal entry, step buttons, repeat-on-hold, and accessibility actions.

Spreadsheet includes shared formulas, virtualized rows and columns, frozen panes, row/column resizing, editing, range selection, touch fill, clipboard batches, and undo/redo. Light/dark browser comparisons and iPad checks cover formula recalculation, history, range fill, clipboard paste, and read-only/empty states. Native hardware-keyboard grid navigation and drag selection/fill with edge autoscrolling remain unimplemented; touch uses explicit range/fill modes. Frozen columns follow Reanimated scroll values on the UI thread; the header stays outside vertical scrolling. Physical-device scrolling, Android visuals, and full screen-reader traversal remain unverified.
